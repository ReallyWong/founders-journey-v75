## ✨ 为什么是这款游戏

- 🎯 **教育性**：每个事件都配一条真实创业课（Runway 管理、监管周期、Keeper Test、桥接贷款……），改编自真实商业史
- 🌍 **真实感**：10+ 行业赛道（软件/硬件/游戏/能源/医药/文娱……）各有专属机制；北京、上海、深圳、香港、东京、纽约、以色列等创业热土各有本地事件
- 🎬 **剧本模式**：真实历史剧本——「2008 年做团购」「2020 年做口罩」，固定事件链 + 真实结局
- 🏆 **完整创业周期**：种子 → A → B → C 轮融资阶梯，团队随融资扩张，IPO 要求团队 ≥10 人
- 🔥 **真实模式**：单次生命、不能读档——像真正的创业一样没有重来
- 😇 **隐藏职业**：赚到钱后解锁天使投资人、VC/PE 基金视角

## 🚀 快速开始

```bash
git clone https://github.com/reallywong/founders-journey.git
cd founders-journey
npm install
npm run dev        # http://localhost:3000
```

生产构建：`npm run build`（产物在 `dist/`，任何静态托管都能跑）。

## 💌 投稿你的真实创业故事

这游戏最宝贵的资产是**事件题库**——我们像美剧《硅谷》改编真实事迹一样改编真实商业史。
如果你经历过（或见证过）值得上这一课的时刻，欢迎投稿：

👉 [**📖 投稿一个真实创业事件**](https://github.com/reallywong/founders-journey/issues/new?template=startup-story.yml)

只需要：事件描述 + 2~4 个选项 + 每个后果 + 一条「创业课」。我们会署上你的 GitHub ID。

## English

**An open-source entrepreneurship simulation game inspired by shows like HBO's *Silicon Valley* — real startup history, playable.**

Pick a character and a startup hub (Beijing, Shanghai, Shenzhen, Hong Kong, Tokyo, New York, Tel Aviv…), choose an industry track
(consumer app, hardware, games, energy, biotech, entertainment…), and survive the full founder journey:
customer discovery, investor pitches, multi-round funding (Seed → A → B → C), hiring, cash-flow crises, and either the IPO bell or bankruptcy court.
Every in-game event is paired with a real business lesson drawn from documented startup history.

- **Play online**: https://reallywong.github.io/founders-journey/
- **Quick start**: `npm install && npm run dev`
- **Contribute real startup stories as game events**: [submit here](https://github.com/reallywong/founders-journey/issues/new?template=startup-story.yml)
- **License**: [MIT](LICENSE)
