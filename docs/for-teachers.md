# 教学使用指南 · For Teachers

> 一页上手：把《创业人生》带进课堂。

## 为什么适合课堂

- 单局 20–40 分钟，正好一节课
- 每个事件结尾自带「创业课」，天然形成课后讨论点
- 零安装：浏览器打开即玩，学生用自己的设备即可

## 推荐的课堂玩法

### 🏫 入门课（1 课时）
1. 全班统一选择：**同一地区 + 同一行业 + 🎓 教学难度**
2. 学生独立打完前 12 个月
3. 讨论题：
   - 你的 Runway 还剩几个月？哪个决策最伤现金流？
   - 有人拿到 TS 了吗？TS 和到账有什么区别？

### 🏆 Capstone  Tournament（计划中）
同 seed 多人限时比拼——所有学生从完全相同的开局出发，
比谁活得更久 / 估值更高。配合「真实模式」（单次生命、不能读档）效果最佳。
（多人排行需要服务端支持，见 [路线图](../README.md#-路线图)，欢迎共建。）

### 🎬 剧本研讨课
统一玩「2008 年做团购」或「2020 年做口罩」，
把游戏结局和真实历史结局对照讨论：风口、周期与纪律。
